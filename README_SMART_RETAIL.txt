LOGIN:
Admin : admin / kelompok 8

CARA MENJALANKAN DI WINDOWS:
1. Install Python 3.
2. Buka folder proyek di VS Code.
3. Buka Terminal.
4. Jalankan:
   python main.py

Database menggunakan SQLite dan akan menggunakan file smart_retail.db.
